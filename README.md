# LanTalk
LAN内で使う小さなチャットルーム(Electron + WebSocket)。

## 使い方
```
npm install
npm start
```
- 誰か1人がホストとして起動すると、部屋一覧にその端末のLAN IPが表示されます。
- 他の端末は初回のニックネーム設定で「サーバーIP」にそのIPを入力して参加します(空欄なら自分の端末のサーバーを使用)。
- 通信は暗号化されません(ws://)。部屋のパスワードも平文で流れるため、信頼できるLANでのみ使い、他で使い回すパスワードは設定しないでください。
- ポートは 7823、LAN内(プライベートIP)からの接続のみ許可します。他のサイトのページからの接続や、IPアドレス以外のホスト名(`mac.local` など)での接続は拒否します。IPアドレスで開いてください。
- 履歴はメモリ上のみで、ホストを終了すると消えます。
- `Cmd/Ctrl+Shift+C` でウィンドウの表示/非表示。画面右下の角にカーソルを置いても出てきます。
- 「⤡」で、最新の1件と入力欄だけの小さい表示になります(後ろから画面を見られたくないとき用)。
- 使っていない間(フォーカスもカーソルも無いとき)は、ウィンドウが薄くなり、文字がぼかされます。カーソルを乗せるか、フォーカスすると元に戻ります。薄さとぼかしの強さは `style.css` の `--idle-opacity` / `--idle-opacity-mini` / `--idle-blur` で調整できます。
- 他の人からメッセージが来て、ウィンドウを見ていないときは、画面の右上にLanTalkのアイコンと点だけが10秒出ます(名前も本文も出しません)。押すとウィンドウが開きます。表示時間は `main.js` の `NOTIFY_MS` です。
- 部屋一覧のIPを押すと、スマホ用のURLをコピーできます。

## スマホ・別PCからブラウザで使う(PWA)
ホストのLanTalkは、WebSocketと同じポートで画面も配信します。同じLANの端末のブラウザで次を開くだけで参加できます。

```
http://<ホストのIP>:7823
```

- **iPhone(Safari):** 共有ボタン →「ホーム画面に追加」
- **Android(Chrome):** メニュー →「ホーム画面に追加」
- **注意:** LANのIPへHTTPでアクセスするため、オフライン対応(Service Worker)とChromeの「インストール」ボタンは使えません。ホーム画面に追加したアイコンから開く使い方になります。
- ホットコーナーやミニ表示など、ウィンドウの操作はデスクトップ版だけの機能です。
