# LanTalk
LAN内で使う小さなチャットルーム(Electron + WebSocket)。

## 使い方
```
npm install
npm start
```
- 誰か1人がホストとして起動すると、部屋一覧にその端末のLAN IPが表示されます。
- 他のPCのLanTalkは、初回のニックネーム設定の画面に「近くのLanTalk」として同じLANのホストが自動で並びます。選ぶだけで参加できます(見つからないときは「参加先のIP」にIPを入力。空欄なら自分の端末がホスト)。
- スマホは、ホストの部屋一覧のIPを押すとQRコードが出ます。読み取るとブラウザで開きます。
- 通信は暗号化されません(ws://)。部屋のパスワードも平文で流れるため、信頼できるLANでのみ使い、他で使い回すパスワードは設定しないでください。
- ポートは 7823、LAN内(プライベートIP)からの接続のみ許可します。他のサイトのページからの接続や、IPアドレス以外のホスト名(`mac.local` など)での接続は拒否します。IPアドレスで開いてください。
- 荒らし対策として、次の上限があります。部屋は最大50個、部屋の作成は1人あたり1分に10回、パスワード付きの部屋への入室の試行は1分に5回、1つのIPからの接続は20本まで。
- 同じ部屋で、別の人が同じニックネームを名乗ることはできません(なりすまし対策)。
- **履歴は、ホストの端末に保存されます**(ホストを再起動しても、部屋と履歴が残ります)。保存先は、本人だけが読めるファイルです(macOSなら `~/Library/Application Support/lantalk/lantalk-data.json`)。パスワードはハッシュで保存され、平文では残りません。発言のある部屋は、7日間だれも使わなければ片付けられ、一度も発言がなかった部屋は30分で片付けられます。メニューバー(トレイ)の「履歴をすべて消す…」で、まとめて消せます。
- ホストが再起動した・通信が切れたときは、自動で同じ部屋に入り直します。
- `Cmd/Ctrl+Shift+C` でウィンドウの表示/非表示。画面右下の角にカーソルを置いても出てきます。
- 「⤡」で、最新の1件と入力欄だけの小さい表示になります(後ろから画面を見られたくないとき用)。
- 使っていない間(フォーカスもカーソルも無いとき)は、ウィンドウが薄くなり、文字がぼかされます。カーソルを乗せるか、フォーカスすると元に戻ります。薄さとぼかしの強さは `style.css` の `--idle-opacity` / `--idle-opacity-mini` / `--idle-blur` で調整できます。
- 他の人からメッセージが来て、ウィンドウを見ていないときは、画面の右上にLanTalkのアイコンと点だけが10秒出ます(名前も本文も出しません)。押すとウィンドウが開きます。表示時間は `main.js` の `NOTIFY_MS` です。

## インストーラーを作る
```
npm run build        # いまのOS向け
npm run build:mac    # mac (dmg) / build:win / build:linux
```
`v1.0.0` のようなタグをpushすると、`.github/workflows/release.yml` がmac・Windows・Linux向けのインストーラーを作って、GitHub Releasesに**下書き**として置きます(公開は人が決めます)。Apple Developer ID での署名・公証はしていません(macにはad-hoc署名を付けています)。初回起動で警告が出ます。
- **macOS:** 「開発元を確認できません」と出たら、アプリを右クリック →「開く」。それでも開けないときは、システム設定 → プライバシーとセキュリティ →「このまま開く」。
- **「壊れているため開けません」と出たとき(v1.0.0 のmac版):** 署名が壊れていた版です。`xattr -cr /Applications/LanTalk.app` を実行すると開けます。v1.0.1 以降は直っています。
- **Windows:** 「詳細情報」→「実行」。

## スマホ・別PCからブラウザで使う(PWA)
ホストのLanTalkは、WebSocketと同じポートで画面も配信します。同じLANの端末のブラウザで次を開くだけで参加できます。

```
http://<ホストのIP>:7823
```

- **iPhone(Safari):** 共有ボタン →「ホーム画面に追加」
- **Android(Chrome):** メニュー →「ホーム画面に追加」
- **注意:** LANのIPへHTTPでアクセスするため、オフライン対応(Service Worker)とChromeの「インストール」ボタンは使えません。ホーム画面に追加したアイコンから開く使い方になります。
- ホットコーナーやミニ表示など、ウィンドウの操作はデスクトップ版だけの機能です。

## 開発・検証
動いているアプリを止めずに試せるよう、ポートと保存先を環境変数で変えられます。

```
LANTALK_PORT=7899 LANTALK_USER_DATA=/tmp/lantalk-test npm start
```
